A Python program that writes a single deadpan one-line review of a flat-pack spare screw — the leftover screw that was never needed, can never be thrown away, and ends up outlasting the furniture it came with — to `/output/entry.txt`.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the review line exactly to `/output/entry.txt`, printing nothing else. It uses only the Python standard library.
